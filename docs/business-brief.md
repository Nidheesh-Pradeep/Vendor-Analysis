# Vendor Performance & FM SLA Analysis

## Audience
Procurement manager, FM contract manager, or operations manager.

## Business goal
Identify supplier cost, delivery, quality, compliance, and service-level risks.

## Decisions supported
- Which vendors should be reviewed?
- Where should the team investigate further?
- What follow-up action should be considered?

## Project scope
Analyze purchase-order data from Kaggle and a separate, clearly labeled simulated FM work-order dataset.

## Data limitations
The procurement data is public and does not represent a UAE company. The FM work orders and SLA targets are simulated. The dataset has a limited number of suppliers.

## Tools
Python, SQL, Excel, and Power BI.
